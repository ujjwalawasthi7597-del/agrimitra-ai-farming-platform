## 📌 About the Project

**AgriMitra** is an AI-powered farming and crop management platform designed to help farmers make informed agricultural decisions.

Farmers often face challenges related to crop diseases, unpredictable weather, irrigation planning, farming expenses, and access to reliable agricultural information.

AgriMitra brings these essential farming tools together in one platform, combining Artificial Intelligence, weather intelligence, and digital farm management.

The platform aims to make agricultural information more accessible, practical, and understandable for farmers across India.

## ✨ Key Features

### 🌿 1. AI Crop Disease Detection
- Upload crop leaf images for AI-powered analysis.
- Identify possible plant diseases and visible symptoms.
- Understand potential causes and preventive measures.
- Receive AI-generated crop care suggestions.
- Get preliminary insights to support further expert diagnosis.

### 🤖 2. AI Farming Assistant
- Interactive AI-powered farming chatbot.
- Get guidance on crop selection and cultivation.
- Ask questions about fertilizers, pests, and crop diseases.
- Receive irrigation and seasonal farming guidance.
- Get simple, understandable agricultural explanations.

### 🌦️ 3. Weather Monitoring
- Real-time weather information.
- Temperature and humidity monitoring.
- Rainfall and wind information.
- Weather forecasts.
- Weather-based farming alerts and recommendations.

### 💧 4. Smart Irrigation Recommendations
- Crop-based irrigation guidance.
- Weather-aware watering suggestions.
- Recommendations based on crop growth stages.
- Support for more efficient water management.

### 🚜 5. Farm & Crop Management
- Manage farm information and plots.
- Maintain crop records.
- Track sowing and harvesting dates.
- Organize farming activities.
- Monitor crop growth schedules.

### 💰 6. Expense & Yield Tracking
- Record seeds, fertilizers, labour, and other expenses.
- Track harvest quantity and selling prices.
- Calculate farming expenses and revenue.
- Monitor estimated profit through analytics.

### 🏛️ 7. Government Scheme Assistant
- Understand agricultural government schemes.
- Explore eligibility requirements and benefits.
- Get explanations of required documents.
- Access simplified information about application procedures.

### 👨‍🌾 8. Expert Consultation
- Submit agricultural questions.
- Share crop-related images.
- Request expert assistance.
- Track consultation progress.

### 🌐 9. Regional Language Support
- Farmer-friendly interface.
- English and Hindi support.
- Multilingual AI assistance.
- Designed to improve accessibility for Indian farmers.

## ⚙️ Environment Variables

Configure the required environment variables in your backend or deployment environment.

Create a `.env` file:

```env
PORT=5000

MONGODB_URI=your_mongodb_connection_string

JWT_SECRET=your_secure_jwt_secret

AI_API_KEY=your_gemini_api_key

WEATHER_API_KEY=your_openweather_api_key
```

**Important:** Never expose API keys, database credentials, or JWT secrets in frontend code or commit your `.env` file to GitHub.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/agrimitra-ai-farming-platform.git
```

### 2. Navigate to the Project

```bash
cd agrimitra-ai-farming-platform
```

### 3. Install Dependencies

For the frontend:

```bash
cd frontend
npm install
```

For the backend:

```bash
cd ../backend
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the backend directory and configure the required API keys and database credentials.

### 5. Start the Backend

```bash
npm run dev
```

### 6. Start the Frontend

Open another terminal:

```bash
cd frontend
npm run dev
```

*Note: Adjust the folder names and scripts according to the actual repository structure.*
